# 避難所レイアウト検討ツール

避難所の運営訓練や検討に使用するための、Web ベースのレイアウト検討ツール集です。
2026-05 のオーバーホールで、メニュー画面から呼び出せる **3 つの独立ツール** 構成になりました。

[避難所レイアウト検討ツール（GitHub Pages）](https://drr-materials-dev.github.io/EvacuationShelterLayoutTools/)

仕様と設計の詳細は [避難所レイアウト検討ツール仕様書.md](避難所レイアウト検討ツール仕様書.md) / [設計書.md](設計書.md) を参照してください。

## 構成

メニュー画面から以下の 3 つのツールへ遷移できます。

### 1. 避難所レイアウト

施設の図面画像の上に区画を配置するメインツール。

* **施設図面の読み込み**: 背景として施設（体育館や教室など）の PNG 画像を読み込めます。
* **縮尺設定**: 図面上の 2 点をクリックし、実距離 (m / cm) を入力することで、正しい縮尺で区画を配置できます。
* **区画の配置**: 共有区画リスト（区画エディタで編集）の区画をドラッグ＆ドロップで配置。移動・回転・（許可された区画のみ）リサイズ可能。
* **テキストブロック**: ボタン → 配置先クリック → モーダル入力（文字列・サイズ・文字色）の 2 段階フロー。配置後はダブルクリックで編集。
* **スナップ**: ユーザー設定（既定 10cm）で配置・移動・リサイズに吸着。
* **データ保存**:
  * `*.layout.json`: 背景画像・縮尺・区画リスト・配置済みアイテムをすべて含む単一ファイル
  * PNG: 現在の表示状態を画像として保存
* **永続化**: 配置状態・縮尺・背景画像はブラウザ内に自動保存され、次回起動時に復元されます。

### 2. 区画エディタ

区画と区画リスト (`*.list.json`) を編集・保存するツール。

* 区画ごとに以下を編集可能:
  * 名称、サイズ（m、スナップ適用）、塗り潰し色、リサイズ可否
  * **区画表示名**: 表示の有無 / 「区画名と区画表示名は同じ」トグル（OFF時は別名入力可）/ 文字色 / フォントサイズ（自動 or メートル単位手動）/ 横位置（左よせ・中央・右よせ）/ 縦位置（上よせ・中央・下よせ）
  * 枠線の有無 / 色 / 太さ（白基調の区画の輪郭を補助）
  * 画像（推奨: 最大 512×512 px・200 KB 以下）と表示モード（区画にフィット / 縦横比維持 / 縮尺指定）
  * 画像縮尺の 0.1 刻み +/- ボタン入力（1.0 未満も直接入力可）
  * 画像回転（1° 刻み、-180〜180°）
* 区画リストの新規作成・読み込み・保存・デフォルトに戻す。
* 保存すると `.list.json` ファイルがダウンロードされ、同時に共有区画リスト（IndexedDB）も更新されます。
* デフォルト区画も編集可能（保存しないと次回起動時に失われる旨を画面に明示）。
* 未保存の状態で画面離脱しようとすると確認モーダルで警告。

### 3. 区画印刷

区画リストから印刷用 HTML を生成するツール。

* 区画リストソース: 共有リスト / `*.list.json` ファイル読込 / デフォルト
* 用紙: A3 / A4 / B5 / カスタム（cm）+ 縦/横 + 上下左右マージン (mm)
* 縮尺入力: 図面上の長さ（m / cm 切替）と印刷上の長さ（cm）
* 各区画ごとの印刷枚数指定
* 配置方式: 単純敷き詰め / 同種グルーピング / 1 種類 1 ページ
* バリデーション: 印刷可能領域より大きい区画があるとエラー一覧を表示し、生成を中断
* 出力: 単一の `.html` ファイル（CSS と画像 base64 をインライン、SVG ベース）。ブラウザで開いて `Ctrl+P` で印刷。
* 各ページ上部に「区画リスト名」と「縮尺」のヘッダ、下端にページ番号フッタを自動付与。
* 区画内の文字は印刷縮尺に合わせて自動拡大縮小（SVG viewBox による「通常サイズで描画して縮尺で配置」方式）。
* 用紙設定と縮尺は自動的に永続化されます。

## 技術スタック

* **Language**: TypeScript
* **Frontend Framework**: React + Vite
* **Routing**: React Router (`react-router-dom`, `createHashRouter`)
* **UI Components**: Mantine v9
* **Icons**: Tabler Icons
* **Canvas Library**: Konva.js (react-konva)
* **Storage**:
  * LocalStorage（軽量ステート・ユーザー設定・レイアウト状態・印刷の用紙/縮尺設定）
  * IndexedDB（背景画像・共有区画リスト - `idb-keyval` 使用）

## 開発・実行方法

### 必要要件

* Node.js (v18 以上推奨)

### セットアップ

```bash
npm install
```

### 開発サーバーの起動

```bash
npm run dev
```

または Windows ではプロジェクトルートの `start-dev.bat` をダブルクリックすると、依存解決と起動を自動で行います。

ブラウザは自動で <http://localhost:5173/EvacuationShelterLayoutTools/> を開きます（ポート使用中なら 5174 以降）。

### 型チェック・lint・ビルド

```bash
npm run typecheck   # tsc -b --noEmit
npm run lint        # eslint .
npm run build       # tsc -b && vite build → dist/ に生成
```

### マルチ操作（同時編集 / 実験的）

同一 LAN 内で複数ユーザーが同時にレイアウトを編集できます。**GitHub Pages 版には含まれません**
（`VITE_COLLAB` フラグでビルドを分離。設計書 §9）。同期されるのは **レイアウト文書全体**です：

* 全階層（floors）・図面背景・縮尺・区画（配置物）の移動／追加／削除・居住者種類／人数
* 区画リストのライブ編集・レイアウト保存（共有スナップショットから）・全削除（ホスト権威）
* **プレゼンス共有**：他ユーザーのカーソル（色付きの点＋表示名）と選択（色付き破線リング）を同じ階層で表示
* **表示名・色のユーザー設定**：ホスト・参加者の双方が、自分のプレゼンス表示名と色を変更できます（端末に保存され再参加・再読込でも引き継ぎ）

> ※ アクティブ階層・選択・ビュー（ズーム／スクロール）は各ユーザーのローカルです（意図的）。

**インストール・準備が必要なのは「ホスト役」の 1 台だけ**です。参加者はインストール不要で、
ホストが表示する URL をブラウザ（PC）で開くだけです（スマートフォン非対応）。

#### 一般利用者向け（インストーラを使う）

1. ホスト役の PC で **「避難所レイアウト（コラボ）」インストーラ（`.exe`）** を実行します。
   インストール時に**使用許諾契約（EULA）**が表示されます。内容に同意するとインストールが進みます。
   （初回起動時に Windows Defender SmartScreen の警告が出ることがあります。署名なし配布のためで、
   「詳細情報」→「実行」で起動できます。社内配布時は管理者に確認してください。）
2. デスクトップ／スタートメニューの **アイコンをダブルクリック**して起動します。
   - 起動と同時に内部で「同期ハブ＋配信サーバ」が動き、ホストはそのウィンドウで編集できます。
   - 初回はファイアウォールの確認が出ます。**「プライベートネットワーク」で許可**してください。
3. 画面上部の **「参加者を招待（URL）」** ボタンを押すと、参加用 URL が表示されます。
4. 参加者は**同じ Wi‑Fi**に接続し、その URL を PC のブラウザで開くと編集に参加できます。
5. 各自、画面上部の **「表示名・色」** ボタンから自分の表示名と色を設定できます。

#### インストールせずに試す（ホスト役の動作確認）

`start-collab.bat` をダブルクリックすると、ビルドして**配布版と同じホストアプリ（Electron）**が起動します
（インストール不要）。ウィンドウ上部の「参加者を招待（URL）」で参加用 URL を表示し、別端末／別ブラウザで開けます。

#### 開発者向け（コマンドで試す）

```bash
# 同一マシンの 2 タブで試す場合
npm run collab:server   # 別ターミナルで同期ハブ（ws://localhost:1234）を起動
npm run dev:collab      # コラボ有効の開発サーバ（VITE_COLLAB=true）

# ホスト用デスクトップアプリを実行 / インストーラを生成
npm run electron:dev    # ビルドして Electron で起動（埋め込みサーバ込み）
npm run electron:build  # Windows 向け NSIS インストーラを release/ に生成（EULA 同梱）
```

> ⚠ **セキュリティに関する免責（必読）**
> - 本マルチ操作機能は **`ws://`（非TLS・平文通信）** です。図面・配置情報は同一ネットワーク上で**盗聴され得ます**。
> - **信頼できる閉じた LAN 内でのみ**使用し、共用 Wi‑Fi やゲストネットワークでは使用しないでください。
> - ルームに接続できる相手は文書を**読み書きできます**（認証・閲覧専用ロールの強制はありません＝紳士協定）。
> - **機微・実在の図面や個人が特定され得る情報を扱わないでください。** 本ツールは利用者がアップロードした内容について責任を負いません。
> - 詳細なリスクと設計判断は [設計書.md](設計書.md) §9.13 / §9.7 / §9.14 / §9.15 を参照してください。
